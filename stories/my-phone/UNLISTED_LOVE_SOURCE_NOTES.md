# 未公开恋人 · 原稿恢复记录（开发用）

作品外壳名称：**My Phone**。本文件只记录已从既有《未公开恋人》剧情整合档案恢复的内容，不是游戏运行时脚本，也不代表所有场景已经实现。

## 故事与结局
玩家与朴炡禹秘密交往将近三年；因他与虚构女演员韩瑞允的同行照片和关于行程的谎言发生信任危机。炡禹在未事先商量的情况下公开恋情，随后双方和解。已恢复结局仅 **ENDING 01「不再隐藏」**。不可混入《越界关系》的婚外恋剧情或另外两个结局。

## 已确认的互动顺序
1. 解锁手机，X 出现同行绯闻；闺蜜提醒玩家。
2. KKT 与炡禹对话，玩家选择回复后必须再点击发送。
3. 第一次语音来电：接听/拒接；拒接后再次拨打。
4. 炡禹发来密集挽留消息，尹材赫、朴志焄、苏庭焕联系玩家。
5. 第二轮争执，玩家可提出休息、分手或暂不联系；炡禹第二次来电。
6. 闺蜜通知炡禹已公开恋情，X 显示声明。
7. Instagram 私信请求增加；首次查看私信触发炡禹道歉。
8. 和解后进入「不再隐藏」；结局后手机仍可浏览。

## 已恢复的玩家回复选项（韩文原文 / 中文）

### 初次追问
- 오빠 지금 어디야? / 欧巴你现在在哪里？
- 오빠, 인터넷에 올라온 사진 봤어? / 欧巴看到网上的照片了吗？
- 오빠 나한테 거짓말한 거야? / 欧巴骗我了吗？

### 第二轮追问
- 왜 숙소라고 했어? / 为什么说自己在宿舍？
- 한서윤 선배랑 무슨 사이야? / 你和韩瑞允前辈是什么关系？
- 나한테 할 말 없어? / 你就没有什么话要说吗？

### 解释要求
- 오늘 어디 있었는지 솔직하게 말해 줘. / 如实告诉我今天在哪里。
- 제대로 설명해 줘... / 好好解释给我听……
- 나한테 숨기는 거 없이 얘기해. / 不要再瞒着我了。

### 情绪与信任
- 오빠, 나 이제 진짜 지쳤어... / 欧巴，我现在真的累了……
- 근데 왜 나한테까지 거짓말했어? / 可是你为什么连我也要骗？
- 오빠, 나 이제 오빠 말을 어떻게 믿어...? / 欧巴，我现在到底要怎么相信你……？

### 是否继续交往
- 나 오늘 너무 피곤해... 이제 그만 얘기하고 잘래. / 我今天真的太累了……就聊到这里吧，我要睡了。
- 오빠... 나 이제 우리 관계를 더는 이어 갈 자신이 없어. 우리 헤어지자. / 欧巴……我已经没有信心继续维持这段关系了。我们分手吧。
- 나 이제 오빠 말 듣고 싶지 않아. 더 이상 연락하지 마. / 我现在不想再听欧巴说话了。不要再联系我了。
