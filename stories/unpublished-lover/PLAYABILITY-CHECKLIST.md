## 下一次验收的最低通过标准

1. 从输入昵称和出生年份开始，手动输入密码 `040928` 解锁。
2. 玩家每一步手动操作才能触发对应剧情，绝不自动替玩家发送选择。
3. KKT、X、Instagram之间切换时消息继续到达，且已读状态和存档一致。
4. A/B/C三条主线各完整跑通一次，结局卡可关闭并继续使用手机。
5. `npm run typecheck`、`npm test`、`npm run build` 均实际执行成功，记录构建日志。
6. 正式公开前单独确认所有用户照片的使用授权。
